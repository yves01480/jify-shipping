# Jify Shipping 入門：讓運費跟著購買數量走

[下載 v3.9.2 安裝 ZIP](https://github.com/yves01480/jify-shipping/releases/download/v3.9.2/jify-shipping.zip) · [返回功能介紹](../README.md)

這份教學先設定一個商品，驗證「買 3 件運費 NT$100、買 8 件運費 NT$150」。範例金額以商店設定為新台幣為前提。

## 1. 安裝外掛

準備 WordPress 5.8+、PHP 7.4+ 與已啟用 WooCommerce 的測試站。

下載上方 ZIP，在 WordPress **外掛 → 安裝外掛 → 上傳外掛** 選取檔案、安裝並啟用。先使用傳統購物車／結帳頁完成此流程；區塊結帳的相容性需另外驗證。

## 2. 把 Jify Shipping 加進運送區域

到 **WooCommerce → 設定 → 運送 → 運送區域**，編輯測試地址對應的區域，新增 **Jify Shipping** 運送方式並確認啟用。

只設定商品規則還不夠；地址必須符合有提供此運送方式的區域。

## 3. 設定一個商品

新增或編輯一個需要運送的簡單商品，到 **商品資料 → Jify Shipping** 啟用該商品的 Jify 運送設定。

在數量／運費規則中新增兩列並儲存商品：

| 數量或範圍 | 運費 |
|---|---:|
| `1-5` | `100` |
| `6-10` | `150` |

每個區間的金額收取一次。規則請勿重疊；同時符合多個區間時，程式採用第一個符合的規則。

## 4. 用顧客角度驗證

清空測試購物車，只加入剛設定的商品，輸入符合運送區域的地址並選取 Jify Shipping。

| 操作 | 應看到的結果 |
|---|---|
| 購買 3 件 | 運費 NT$100 |
| 改成 5 件 | 運費仍是 NT$100 |
| 改成 6 件或 8 件 | 運費 NT$150 |
| 改成 11 件 | 超出設定範圍，進入待報價流程 |

這是供你操作的預期結果，並非已在你的網站完成的測試紀錄。

## 5. 再試人工報價

多種 Jify 商品混買、Jify 與一般商品混買，或單一商品數量超出規則時，會進入待報價流程。

在前台填寫通知表單並送出，到 **Jify Setting → 通知管理**確認待報價購物車、填入運費。保持原瀏覽器與購物車內容，回到結帳頁確認報價已載入，並檢查通知信是否送達。

報價綁定目前購物車識別碼；更換裝置、清除 session 或變更購物車後，請重新確認。通知信不會重建購物車，填報價也不是更新既有 WooCommerce 訂單。

目前的結帳限制包含前台按鈕停用，不能視為對所有 API 或第三方結帳入口的強制封鎖。需要未報價即禁止下單的商店，應先補強並驗證伺服器端阻擋。

## 沒看到預期結果？

- 沒有運送方式：檢查商品是否需要運送、地址是否符合區域，以及區域是否已新增 Jify Shipping。
- 進入待報價：先只保留一種商品，檢查數量是否在已設定區間內。
- 報價未更新：確認仍使用原購物車，並檢查前台結帳更新及網站快取設定。
